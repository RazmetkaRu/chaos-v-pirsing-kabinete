# Хаос в пирсинг-кабинете

Короткий point-and-click студии **Разметка**.
Открыть: [index.html](./index.html) локально или через GitHub Pages.

Живая страница (после прогрева Pages): https://razmetkaru.github.io/chaos-v-pirsing-kabinete/

## Во что играть

Утренняя смена. Мастер на съезде. Клиент в лифте.
Каждому предмету выбираешь действие: осмотреть / взять / изолировать / подготовить / согласовать / применить.

Победа — не «проткнул ухо». Победа — сухие пакеты, разведённые зоны, честный разговор про анатомию.

Игра **не учит** технике прокола и не показывает его крупно.

## Что в каноне не бред

- Мокрый пакет после автоклава считают скомпрометированным (wicking). Его не сушат феном.
- Украшение с витрины не стерильно, пока не прошло студийную подготовку.
- «Хирургическая сталь» без стандарта ≠ ASTM F138. Внешняя резьба и заусенец не идут в свежий канал.
- ASTM F136 + внутренняя резьба / threadless — нормальный кандидат *после* цикла.
- Серебро и напыление — не в незаживший канал.
- Пистолет в студии не инструмент.
- Индустриал требует посадку. Чужой референс из ленты не важнее уха клиента.
- Согласие и отказ — часть работы.

## Дисклеймер

Вымысел про протокол и характер. Живые проколы — только у специалиста в студии, которая может показать стерилизацию, материал и согласие.
